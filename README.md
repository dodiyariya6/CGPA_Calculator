# CGPA Calculator

A simple web-based calculator for calculating **SGPA and CGPA** across semesters.

### Features

* Calculate SGPA and CGPA
* Add subjects, credits, and grades
* Save **Sem 1–8** academic history locally
* Automatically calculate cumulative CGPA
* Simple, responsive interface
* No backend or database

### Tech Stack

* HTML
* CSS
* JavaScript
* Browser LocalStorage

### Privacy

Semester history is stored locally in the browser and is **not uploaded to GitHub or any server**.

### Run

Open `cgpa_calculator.html` in your browser.
